## Persistent footer content {#footer-content}

The footer below this page is defined once in `sitewide-content.md`. Its
copyright message remains the same across routes.

## Build information {#build-information}

This demo also enables generated build information. Norna adds the build time
using the configured locale and time zone, keeping generated publication data
separate from editorial page content.
