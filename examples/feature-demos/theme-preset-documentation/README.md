# Documentation Theme Preset

This site renders the shared preset-comparison content with the complete
`documentation` preset and no overrides.

[Live demo](https://janga.github.io/norna/examples/feature-demos/theme-preset-documentation/)
|
[View source](https://github.com/janga/norna/tree/main/examples/feature-demos/theme-preset-documentation)

Run it from the repository root:

```sh
node bin/norna.mjs --site-dir examples/feature-demos/theme-preset-documentation/site dev:local
```

All four preset examples use identical content and assets. The dog photos are
CC0 images by Bicanski, sourced from Pixnio; attribution is included in the
captions even though the licence does not require it.
