# Docusaurus Docs Navigation

This is evaluation material, not a canonical Norna example or a faithful visual
copy of the source site. It preserves a representative page hierarchy and
substantial source text so Norna's navigation can be evaluated with realistic
content. Source-specific components, assets, metadata, and internal links were
removed during adaptation.
