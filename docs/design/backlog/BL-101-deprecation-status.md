# BL-101: Deprecation Status

## Outcome

Allow Norna documentation to mark a page or other supported documentation
scope as deprecated, explain the replacement, and optionally identify the
version in which the old material became deprecated or may be removed.

## Status

This is an intentionally incomplete design item, not an implementation-ready
specification. It depends on `BL-100` Future Versioning Foundation and must be
clarified after that model exists.

## Direction

Treat deprecation as lifecycle metadata rather than as a new generic callout
style. Start with page-level status; use existing semantic warnings for
section-level guidance until a stronger need is demonstrated. The final model
must remain visible in text, accessible, searchable, and explicit about any
replacement.
