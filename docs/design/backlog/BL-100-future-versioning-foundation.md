# BL-100: Future Versioning Foundation

## Outcome

Define a future versioning model that can identify which documentation,
configuration, commands, and migration guidance belong to which Norna version.

## Status

This is an intentionally incomplete design item, not an implementation-ready
specification. It must be clarified before work begins and reconciled with
the existing deferred work on versioned documentation.

## Dependency And Questions

The model must establish version identity, supported-version policy, URL and
search behavior, and how documentation states are represented before dependent
features are implemented.
