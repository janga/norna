# BL-102: Semantic Callout Terminology

## Outcome

Explain in the HTML and reference documentation that Norna's **Semantic
callouts** are the counterpart to constructs called *custom containers* or
*admonitions* in other documentation tools.

## Direction

Use **Semantic callouts** as Norna's user-facing term. Explain that Norna uses
a closed set of meanings rather than user-defined block types, and keep
`details` documented separately as a disclosure.

## Status

This is a documentation task for later implementation. It is not a request to
expand Norna's supported callout syntax or meaning set.
