# Linux

## Requirements

Install Node.js 22.12 or later. Install ImageMagick too if your site uses
raster images.

### Check Node.js

```sh
node --version
```

## Local preview

From an installed site project's directory, start Norna:

```sh
npm run norna:dev
```

Open the address printed in the terminal. Keep the terminal running while
you edit your site.
