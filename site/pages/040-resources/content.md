# Resources

Use this area when you need to look beyond the introductory workflow. Different
resources answer different questions: the reference defines exact behavior,
examples show complete results, and the FAQ addresses common problems.

## Find an exact answer {#reference}

Reference documentation is the source of truth for Norna's files, syntax,
settings, commands, defaults, and constraints. The **Reference documentation**
page in this area helps you choose the right Markdown document based on what you
are trying to change.

## Inspect a working result {#examples}

Use **Examples** in the main navigation when the rendered result matters more
than the full contract. Complete-site examples show how the parts fit together;
focused examples isolate themes, media blocks, notes, and shared site elements.

## Resolve a common problem {#faq}

Use **FAQ** in the main navigation for practical questions about installation,
site projects, content, images, maintenance, and publishing. The FAQ gives a
direct answer and points to reference material when the complete rules matter.

## Use the documentation with AI {#ai}

The [AI-readable documentation index](/llms.txt) links directly to the
authoritative Markdown sources. An AI assistant can use that index to find the
same exact contracts that a human reader uses.
